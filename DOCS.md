# Морзе — краткая документация

Два приложения с одним декодером: **часы** (`app`, Wear OS) и **телефон** (`phone`, Android 8+).
Слушают микрофон и в реальном времени расшифровывают морзянку на слух. Тон и скорость определяются
автоматически, интернет не нужен.

## Установка
Проект открывать **папкой** (не zip) в Android Studio, дождаться Gradle Sync.

| Куда | Как |
|---|---|
| Телефон | Включить отладку по USB, подключить кабелем, выбрать модуль `phone`, Run ▶. Либо `adb install -r phone/build/outputs/apk/debug/phone-debug.apk` |
| Часы | Отладка по Wi-Fi: `adb pair IP:порт` (код с часов), затем `adb connect IP:порт`, затем `adb install -r app/build/outputs/apk/debug/app-debug.apk` |

Файлы APK лежат в `<модуль>/build/outputs/apk/debug/`. Файловым менеджером на часах APK не поставить.
`adb` — в папке `platform-tools` Android SDK.

## Использование

**Телефон.** «Слушать» → разрешить микрофон. Сверху: найденный тон, скорость (WPM), индикатор «ключ нажат».
Большая буква — последний символ, под ней текущий набираемый код, ниже весь текст с прокруткой.
**RU/EN** — алфавит (по умолчанию русский), **Сброс** — очистить текст, «Стоп» — остановить.

**Часы.** Чёрный экран, один маленький тусклый символ у правого края (со стороны кнопок).
Касание — слушать/стоп, долгое нажатие — RU/EN. `·` — слушает, символов нет; `!` — ошибка (нет микрофона).
Сторона экрана и размер символа — `MorseScreen.kt` (`BUTTONS_ON_RIGHT`, `fontSize`, `Faint`).

**Для лучшего приёма:** держать устройство ближе к источнику звука, без громких посторонних тонов рядом.

## Что важно знать
* Первые несколько секунд идёт калибровка (~14 элементов): первые 1–3 символа могут быть неверными.
* `?` — код не распознан (искажение или нет такой буквы в таблице).
* Работает, пока приложение открыто и экран включён; при сворачивании запись останавливается.
* Диапазон проверки: тон 360–1140 Гц, скорость ~3–24 WPM, шум до 0 дБ SNR. Быстрее ~25 WPM и в сильной
  реверберации точность падает.
* Пунктуация выключена по умолчанию (`MorseTables.build(alphabet, punctuation = true)`).
* Приложения для Android в момент передачи не собирались автоматически: проверялось только ядро `morse-core`.

## Если что-то не так
| Симптом | Что делать |
|---|---|
| Пишет «нет тона» | Поднести ближе к источнику, сделать звук громче, проверить, что тон 300–1200 Гц |
| Мусорные символы | Подождать калибровку; уменьшить посторонний шум; проверить RU/EN |
| `!` / «Нужен доступ к микрофону» | Выдать разрешение «Микрофон» в настройках приложения |
| Gradle Sync не проходит | Нужен интернет при первом синке; версии в `build.gradle.kts` можно обновить по подсказке Studio |

## Устройство (кратко)
`morse-core` (чистый Kotlin): поиск тона (банк Гёрцеля) → демодуляция и огибающая (5 мс) → детектор
нажатия по наклону огибающей → устойчивая подгонка длины точки на старте → кластеризация точка/тире и
паузы → символы. Проверка ядра на ПК: `./gradlew :morse-core:run --args="запись.wav ru"`; самопроверка на
синтетике — `morse.cli.SelfTestKt`. Подробнее — `README.md`.
